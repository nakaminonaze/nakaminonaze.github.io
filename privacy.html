プライバシーポリシー（nakaminonaze uploader）

最終更新日：2026年10月17日

1. 対象

本ポリシーは、YouTube チャンネル「なかみのなぜ」の運営者が個人で使用するツール「nakaminonaze uploader」（以下「本ツール」）に適用されます。本ツールは運営者本人の Google アカウントでのみ使用し、第三者には提供していません。

2. 取得する情報

本ツールは YouTube API サービスを利用し、運営者本人の許可のもとで以下を扱います。

  • 運営者の YouTube チャンネルへの動画アップロード、およびタイトル・説明文などの設定
  • 運営者のチャンネルと動画の統計情報（再生数・登録者数など）の読み取り

運営者以外のユーザーの個人情報は取得しません。

3. 利用目的

取得した情報は、チャンネルへの動画投稿と、動画の成果の確認のためにのみ使用します。広告、販売、第三者への提供には使用しません。

4. 保存と削除

認証情報（アクセストークン）は運営者が管理する環境に安全に保存し、公開しません。運営者は Google アカウントの権限ページ からいつでも本ツールのアクセス権を取り消すことができます。

5. 利用しているサービス

本ツールは YouTube API サービスを利用しています。YouTube API の利用には YouTube 利用規約 と Google プライバシーポリシー が適用されます。

English summary

"nakaminonaze uploader" is a private tool used only by the owner of the YouTube channel "Nakami no Naze". Through the YouTube API Services, it uploads videos to the owner's own channel and reads that channel's statistics, with the owner's consent. No data from other users is collected, and no data is sold or shared with third parties. Access can be revoked at any time from Google Account permissions. Use of the YouTube API is subject to the YouTube Terms of Service and the Google Privacy Policy.
